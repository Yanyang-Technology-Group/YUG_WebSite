晏阳联合政府网站 · Windows 10/11 x64 免安装部署

1. 将 ZIP 复制到目标电脑，右键“全部解压缩”。不要在 ZIP 内直接双击。
2. 打开解压后的文件夹，双击“启动网站.cmd”。网站会在浏览器中自动打开。
3. 点击页面上的“管理模式”，第一次在目标电脑设置超级管理员账号，然后登录发帖或修改网站区域名称与文字。
4. 下次使用仍双击“启动网站.cmd”；关闭浏览器不会停止网站。双击“停止网站.cmd”才会停止服务。
   英文别名 start.cmd、stop.cmd、start-lan.cmd 提供相同功能。

部署包自带经过官方 SHA-256 验证的 Node.js 24.21.0 Windows x64 运行环境。
目标电脑无需安装 Node.js、npm 或其他软件，启动及后台再次导出部署包均无需联网。
每个正式版本均配备 Windows x64 ZIP 和 Linux x64 TAR.GZ；后台“部署与备份”可选择系统下载。
包内保留两种经过校验的运行环境，支持在任一平台离线导出另一平台迁移包。
Linux x64 部署请参阅 README-linux.txt，解压后运行 bash start.sh；停止用 bash stop.sh。
默认仅本机访问：http://127.0.0.1:5173/，管理模式：http://127.0.0.1:5173/admin。
联网优先翻译：登录高级或超级管理员后打开后台“翻译设置”，可视化选择 AI 大模型（兼容 Chat Completions）、DeepL 或仅离线模型，填写 HTTPS 接口、模型名和密钥后保存并测试连接。AI 大模型可接入 DeepSeek、通义千问等兼容服务；DeepL 也可在启动前用 PowerShell 设置 `$env:DEEPL_API_KEY='你的密钥'`（可选 `$env:DEEPL_API_URL='https://兼容服务/v2/translate'`）作为默认配置。密钥只保存在服务器 `data/translation-settings.json`，页面只显示掩码，不进入文章、日志、备份或部署包。连接测试只发送固定短示例；联网失败时可回退包内离线模型，选择仅离线模型时不会发送文章内容。
端口被占用时，可在此文件夹的命令窗口运行 start.cmd -Port 5174。
支持含空格和中文的文件夹路径。

需要局域网访问时：
在服务器电脑双击“局域网启动.cmd”，再让其他电脑访问“服务器 IPv4 地址:5173”。
首次管理员密码必须先在服务器本机设置。Windows 防火墙提示时可按需求允许专用网络访问。
脚本不会自动修改防火墙。服务器电脑须保持开机；公网部署请另行配置 HTTPS 和反向代理。
从本机访问管理模式时使用 127.0.0.1 地址。

文章、草稿、网站区域文字和管理员配置保存在 data 文件夹，重新启动不会丢失。
网站区域文字保存在 data/site-content.json，文章保存在 data/articles.json。
后台“下载一键部署包”会包含导出时的全部文章、草稿和网站区域内容快照。
迁移包包含已批准的定时发布计划，不会携带原电脑的管理员账号、登录会话、审批记录、意见反馈或操作日志，新电脑须重新设置超级管理员账号。
导出的包包含尚未发布的草稿，请仅分享给需要接管网站的人员。
如需完整备份当前电脑，先停止服务，再将整个网站文件夹另存；请妥善保存 data 文件夹。
故障信息请查看 data/server.log 和 data/server-error.log。

后台 JSON 备份同时包含文章与网站区域文字。导入新版备份时恢复这些内容；旧版纯文章备份仍可导入，只恢复文章，保留当前网站区域文字。
导入前建议先导出当前备份，以便恢复。

管理员权限与内容审批：
支持普通、高级、超级三种管理员等级；旧账号和密码保持不变。
高级和超级管理员均有全站内容、审批、账号管理、网站设置、反馈、日志、备份与部署权限。
只有超级管理员可在“管理员管理”更改其他账号等级，可选择普通、高级或超级管理员。
高级管理员可添加普通或高级管理员，以及管理非超级管理员的启停、密码与删除；不能修改现有账号等级，不能创建、修改或删除超级管理员。
不能更改自身等级；系统至少保留一名启用的超级管理员。
普通管理员只可提交新文章发布或删除文章申请，在“我的申请”查看结果。
高级或超级管理员在“内容审批”查看正文、批准或驳回，可填写处理意见。批准前不会发布或删除文章。
删除目标在等待审批时已经修改，须驳回旧申请再重新提交。
各账号可在“账号设置”修改自己的密码；更改等级、禁用、删除、重置密码会注销目标账号，不影响其他账号。
data/admin.json 保存账号，data/requests.json 保存审批记录。JSON 内容备份不包括账号与审批记录。
审批和文章修改通过同一日志事务提交；中断后下次启动自动完成已提交的写入。
最多 100 个管理员账号、5000 条审批记录，审批文件最多 32 MiB。

容量限制：最多 10000 篇文章（含草稿），且 data/articles.json 的 UTF-8 文件总大小最多 64 MiB。
先达到任一限制即停止新增或扩大内容；超限操作不会修改已经保存的文章。
备份导入请求最多 128 MiB，导入后仍须满足 10000 篇和 64 MiB 的存储限制。
接近上限时，请先导出备份，再清理不再需要的文章。

定时发布：
文章编辑选择“定时发布”，输入未来的北京时间（UTC+8）。普通管理员提交后仍须审批；批准时已过预定时间会立即发布。
高级或超级管理员可修改计划、立即发布，或存为草稿取消计划。网站运行时每秒检查，停机期间到期的计划下次启动会补发。
服务器电脑需保持开机并运行网站，才能按时发布。迁移到新电脑后首次启动也会补发到期的计划。

意见反馈与操作日志：
前台访客提交反馈后显示回执，内容保存在服务器，不会公开。
三类管理员在“意见反馈”查看完整留言、搜索、筛选与标记已读；高级或超级管理员可标记未读。
所有新留言均须填写游戏名称与 QQ 号，后台列表独立列和详情显示，三类管理员均可按这两项搜索。
旧版未采集的身份信息标注“旧版未采集”，无法自动补回；QQ 号不公开或写入操作日志。
旧版浏览器本地留言显示为“未提交”，不会自动上传。
高级或超级管理员在“操作日志”查看只读记录，可按动作、结果、文字搜索；日志不保存密码、QQ、令牌、文章正文或反馈全文。
data/feedback.json 保存反馈，最多 5000 条或 16 MiB（含处理空间）；data/logs.json 滚动保留最近 10000 条且最多 16 MiB。
反馈和操作日志不进入内容备份或迁移包。完整备份请停机后复制整个 data 文件夹。

本网站使用自定义名称和示例内容，不连接真实政务业务系统；留言由本网站管理员查看。
不含国徽、国旗及网站外部跳转链接。

跨平台迁移与版本发布：
后台下载时可选择 Windows x64（ZIP）或 Linux x64（TAR.GZ）。两个平台包都包含经过官方校验的 Windows 和 Linux 运行环境，
因此迁移后仍可在后台离线导出任一平台。Linux 需要 x86_64、glibc 2.28 及以上，具体启停与 SSH 首次设置方法见 README-linux.txt。
每次运行 node scripts/package.mjs 会为 package.json 中的同一版本生成两个平台包，保存到 downloads/版本号/，
release.json 记录文件大小及 SHA-256；旧版本目录继续保留，downloads 根目录的固定文件名同时更新到最新完整发布。
