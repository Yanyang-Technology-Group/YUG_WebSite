# 晏阳联合政府网站

版本：3.0.2。使用 Next.js App Router 静态导出、Cloudflare Pages Functions 和 D1，前台、管理页、API 在同一项目和域名部署。完整部署步骤见 [Cloudflare Pages 部署](docs/cloudflare-pages.md)。Windows / Linux 便携包使用相同 Next 页面和共享 API 逻辑，保留本机文件存储。

采用深红主框架、暖白内容面与金色细节的庄重红色政务视觉风格，使用晏阳联合政府名称和本地示例资讯，不含国徽、国旗或外部跳转链接。

前台默认简体中文，页眉语言按钮打开现代卡片式选择浮层，提供简体中文、繁體中文、English、한국어、日本語、Deutsch、Français、Русский、Español、العربية、Português、Italiano 共 12 种语言。卡片使用各语言原生名称、标明当前选中项，并记住当前浏览器的偏好；按 Esc 或点击浮层外的空白处可关闭。阿拉伯语采用从右向左（RTL）的布局。固定页面、办事指南、图片配文和留言表单使用本地离线语言包，无外部翻译依赖；管理员发布的文章和自定义文字保留原文，后台管理仍使用中文。

首页以深红主框架、暖白内容面、金色细节和清晰的信息分区呈现庄重的红色政务界面，适配桌面和手机浏览。管理登录页延续相同配色，以醒目的站点标识、简洁表单和明确的操作按钮组织登录流程。后台统一红色视觉，保持现代简明布局，以清晰侧栏组织功能，表单间距宽松，表格在自身区域内滚动；手机上管理界面适配视口。后台不提供部署和备份选项，内容迁移通过命令行完成。原有文章、区域编辑、账号权限、审批和反馈功能保持兼容。

首页轮播选用用户提供的游戏建筑截图，展示晏阳大会堂、现代商业街区与夕照站前广场；“城市风貌”画廊收录全部五张截图，另含住宅楼群和传统院落。影像来源统一标注为“晏阳城市建设服务器”。每张图片配有描述性文字，点击可查看大图。画廊标题、图片标题与说明可在后台“网站内容”修改；图片作为本地资源随 Windows 和 Linux 部署包一起提供。

每次成功新登录后，先显示全屏电影感欢迎开场，以深红光影、金色光轨、暖白文字和站点名称呈现当前账号身份，与全站庄重红色政务风格一致；约 2.4 秒后自动进入“管理首页”，查看身份、北京时间、真实文章概况和常用功能入口。可随时点击“进入工作台”或按 Esc 跳过开场；系统启用减少动态效果时直接进入管理首页。刷新已登录会话不会重播开场；会话过期后重新登录时，尚未保存的网站内容草稿优先恢复编辑，并绕过开场。

管理首页中的“重播欢迎开场”可随时重新查看动画，无需退出登录。

提供资讯浏览、搜索、文章与网站内容管理、审批、定时发布、意见反馈、操作日志和 Windows / Linux 便携部署包。源码构建使用 Node.js 22 或 24，并先运行 npm ci 安装依赖；便携包无需安装依赖。

支持普通、高级、超级三种管理员等级。高级管理员拥有全站管理能力；超级管理员还可在“管理员管理”调整其他账号等级。普通管理员发布或删除内容仍需审批。

## 快速启动

在项目根目录运行：

```sh
npm ci
npm run db:migrate:local
npm run dev
```

将 .dev.vars.example 复制为 .dev.vars 并设置至少 32 字符的随机 SETUP_TOKEN。访问 [网站首页](http://127.0.0.1:5173)；进入 [管理模式](http://127.0.0.1:5173/admin/)，输入首次设置密钥并创建超级管理员。开发服务在终端按 Ctrl+C 停止。本机文件存储模式可用 npm run dev:portable 启动。

```sh
npm test
npm run build
npm run verify:build
npm run package
```

build 先生成 Pages 静态目录 out/，再生成便携服务 dist/（node dist/server.mjs 启动）；verify:build 使用临时 D1、隔离文件存储和浏览器验证 Next 页面、权限、反馈、定时发布和日志。package 每次同时生成 Windows x64 ZIP、Linux x64 TAR.GZ 和校验清单，保存在 downloads/3.0.2/，并更新 downloads/ 中的当前下载别名，历史版本保留。两包使用同一套 Next 构建及内容快照，不包含账号、反馈、审批、日志或会话等私有数据。构建和验证通过后再打包，随后运行 node scripts/verification/verify-release.mjs 核验归档。

内容迁移包通过项目目录中的 `npm run package` 导出，从 `downloads/<版本>/` 选择所需平台的部署包。完整备份请先停止网站，再备份整个网站目录并妥善保管私有 `data/`。

Windows 完整解压后双击“启动网站.cmd”。Linux（x86_64、glibc 2.28+）解压后运行 `bash start.sh --no-browser`；局域网运行 `bash start-lan.sh --no-browser`，停止用 `bash stop.sh`。两包都自带校验过的运行环境，目标机器无需安装 Node.js。

发布文章时可勾选自动翻译。Pages 支持 AI 大模型和 DeepL，密钥保存在私有 D1 或 Cloudflare 密钥配置中；每次请求后台处理一种语言，后续请求继续。以下离线模型、离线回退和本机 data/ 设置仅适用于 Windows / Linux 常驻部署。高级或超级管理员进入后台“翻译设置”，可以选择：

- **AI 大模型**：填写兼容 Chat Completions 的 HTTPS 地址（例如 `/v1/chat/completions`）、模型名称和服务密钥，可接入 DeepSeek、通义千问等兼容服务；模型必须返回 `{"translations":["..."]}` JSON。
- **DeepL**：填写 DeepL 的 HTTPS 翻译地址和密钥；也可在首次启动前使用 `DEEPL_API_KEY`、`DEEPL_API_URL` 环境变量提供默认配置。
- **仅离线模型**：文章不会发送到网络服务，但需要部署包中的离线翻译组件可用。

保存后新任务立即采用新配置；“测试连接”只发送固定的短示例，不会上传文章。联网翻译失败时可按开关使用本机离线模型补齐，翻译最多同时处理三种语言，文章公开和审批流程不受影响。联网服务会收到文章字段，请按服务商隐私政策和额度要求配置。密钥只写入服务器私有 `data/translation-settings.json`，接口只返回是否已配置和掩码，不会进入文章、操作日志、备份或部署包。
