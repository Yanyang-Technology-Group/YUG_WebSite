# 使用说明

晏阳联合政府网站 3.0.2。项目结构见 [目录说明](directory-structure.md)，快速入口见 [项目说明](../README.md)。

Cloudflare Pages 的安装、D1 绑定、首次账号设置、内容导入和运行限制统一见 [Pages 部署说明](cloudflare-pages.md)。Pages 使用 Next 静态页面、Functions API 和私有 D1；以下涉及 data/ 文件、每秒定时器、离线翻译与启停脚本的说明适用于 Windows / Linux 本机部署。Pages 的定时发布由到期后的 API 请求触发，在线翻译按请求分批推进，账号首次设置需要 SETUP_TOKEN。

2.20.0 增加后台可视化翻译设置，支持 AI 大模型（兼容 Chat Completions）、DeepL、仅离线模型、连接测试和密钥掩码；2.19.0 加入联网优先翻译；2.18.0 将本地离线自动翻译调整为最多两种语言并发处理；2.17.0 加入支持 11 种语言的文章发布后自动翻译；2.16.1 移除语言选择面板与首页的说明提示。

2.16.0 新增含简繁中文的前台 12 种语言及卡片式选择浮层、本地离线语言包与阿拉伯语 RTL 布局，自定义内容保留原文。

采用庄重的红色政务信息布局、晏阳联合政府名称和本地示例资讯，不含国徽、国旗或外部跳转链接。

首页采用深红主框架、暖白内容面与金色细节的庄重红色政务风格，以清晰的信息分区和醒目标题组织资讯，适配桌面和手机浏览。管理登录页延续相同配色，以站点标识、简洁表单和明确的操作按钮组织登录流程。后台统一红色视觉并保持现代简明布局，清晰侧栏便于切换功能，宽松表单便于编辑，表格在自身区域内滚动；手机上的管理界面适配视口。后台不提供部署和备份选项，内容迁移使用命令行，完整备份在停止服务后进行。

## 语言切换

前台默认使用简体中文。点击页眉语言按钮打开现代卡片式选择浮层，卡片以原生名称显示：简体中文、繁體中文、English、한국어、日本語、Deutsch、Français、Русский、Español、العربية、Português、Italiano，共 12 种语言。浮层标明当前选中项，选择后会记住当前浏览器的偏好；按 Esc 或点击浮层外的空白处可关闭。阿拉伯语使用从右向左（RTL）的页面布局。

固定页面、办事指南、图片标题与说明、留言表单和提示均提供翻译。管理员发布的文章及后台修改的自定义文字保留原文；后台管理界面仍使用中文。语言包随网站本地保存，并一同进入 Windows 和 Linux 部署包，离线可用，无外部翻译依赖。

发布文章时可勾选自动翻译。高级或超级管理员在“翻译设置”中选择 AI 大模型、DeepL 或仅离线模型，填写服务地址、模型名和密钥并点击“测试连接”。AI 模型需兼容 Chat Completions，并返回按原顺序排列的 `translations` JSON 数组；服务地址必须为 HTTPS。连接测试只发送固定短示例，文章翻译才会按服务商政策发送文章字段。密钥只保存于服务器私有 `data/translation-settings.json`，接口返回掩码，不进入文章、日志、备份或部署包。

文章公开后会生成繁体中文、英语、韩语、日语、德语、法语、俄语、西班牙语、阿拉伯语、葡萄牙语和意大利语译文。联网服务按最多三种语言并发处理；单种语言失败时可回退包内离线模型。管理员可在文章管理中查看翻译状态；失败时，高级或超级管理员可点击重试。选择仅离线模型时文章不会发送到网络；离线组件不可用时只记录失败状态，不影响原文发布。修改文章正文、标题、摘要或来源后，旧译文会失效并按新原文重新生成。

## 源码运行

每版同时提供 Windows 10/11 x64 和 Linux x64 便携部署包。源码构建使用 Node.js 22 或 24，先运行 npm ci 安装依赖；Pages 本地开发先运行 npm run db:migrate:local，配置 .dev.vars 中的 SETUP_TOKEN，再运行 npm run dev。本机文件存储兼容模式在项目根目录运行：

```sh
npm run dev:portable
```

浏览器访问 [网站首页](http://127.0.0.1:5173)。源码服务在运行它的终端按 `Ctrl+C` 停止；以下一键启动、局域网启动和停止 `.cmd` 操作适用于生成的部署目录。

在管理首页点击“重播欢迎开场”可再次查看动画，无需退出登录；减少动态效果开启时仍会跳过。

## 管理账号与内容

每次成功新登录后，先显示与全站庄重红色政务风格一致的全屏电影感欢迎开场：深红光影、金色光轨与暖白文字衬托站点名称和当前账号身份，约 2.4 秒后自动进入“管理首页”。开场期间可随时点击“进入工作台”或按 Esc 跳过；系统启用减少动态效果时直接跳过。管理首页显示当前账号身份、北京时间、真实文章概况和常用功能入口，便于查看内容状态并继续管理。刷新已登录会话会进入管理首页，不重播开场。如果编辑网站区域内容时会话过期，重新登录后会优先恢复尚未保存的草稿编辑，并绕过开场。

点击页面中的“管理模式”（`/admin`），首次在本机设置超级管理员账号。旧版账号和密码保持不变。高级管理员与超级管理员均可新建、编辑、草稿、定时发布、直接发布或删除文章，以及处理审批、管理账号、网站设置、反馈和日志。文章保存在服务器的 `data/articles.json`，发布后前台栏目与搜索会读取最新内容。

超级管理员在“管理员管理”添加账号，或点击其他账号的设置，将其等级设为“普通管理员”“高级管理员”或“超级管理员”。只有超级管理员能调整现有账号等级。高级管理员可添加普通或高级管理员，以及重置非超级管理员的密码、禁用或删除非超级管理员账号；不能创建、修改或删除超级管理员，避免通过重置密码取得等级管理权限。当前账号的密码在“账号设置”修改，不能调整自身等级；系统至少保留一名启用的超级管理员。更改等级、密码或状态后，目标账号需重新登录。

普通管理员只可提交发布和删除申请，在“我的申请”查看结果。高级或超级管理员在“内容审批”查看完整正文并批准或驳回，批准前不会影响访客看到的内容。删除目标在待审期间修改后，须驳回旧申请并重新提交。

## 定时发布、反馈与日志

在文章编辑中选择“定时发布”，输入未来的北京时间（UTC+8）。普通管理员的计划仍须审批；批准时已过预定时间会立即发布。高级或超级管理员可修改计划、立即发布，或存为草稿取消计划。网站运行时每秒检查，关闭期间到期的已批准计划会在下次启动时补发。

三类管理员均可在“意见反馈”查看访客留言、搜索、筛选和标记已读；高级或超级管理员可重新标记未读。前台成功提交后显示回执编号，留言内容不会公开。旧浏览器本地留言会标为“未提交”，不会自动上传。

意见建议、办事咨询和体验反馈均须填写游戏名称（1–40 字）与 QQ 号（5–12 位数字，首位不能为 0），前台和服务器都会校验。管理员在列表的“游戏名称”“QQ号”独立列和留言详情查看这两项信息，也可按游戏名称或 QQ 号搜索；升级前未采集的历史留言会显示“旧版未采集”，不能自动补回。窄屏下可在表格内部横向滚动查看全部列。

高级或超级管理员在“操作日志”查看账号、文章、定时发布、审批、网站设置、备份、部署和反馈处理记录，可按动作、结果及文字筛选。日志只读，记录时间、操作者、对象与结果，不保存密码、QQ 号、会话令牌、文章正文或反馈全文；滚动保留最近 10000 条且最多 16 MiB。

账号保存在 `data/admin.json`，审批记录在 `data/requests.json`，反馈在 `data/feedback.json`，操作日志在 `data/logs.json`，重启后保留。成功操作与对应日志通过同一事务提交，启动时自动完成中断的写入。账号、审批、反馈、日志和会话不会进入 JSON 内容备份或迁移部署包；部署包仅包含文章和网站区域内容快照。完整保留这些资料请停止网站后备份整个 `data` 文件夹。`data/` 是私有运行数据，不可作为源码或公开附件分享。

## 网站区域内容

后台还可修改网站各区域的名称和文字内容，包括网站名称、导航名称、栏目标题、介绍文案、办事指南、互动内容和页脚信息。保存后首页使用最新文字。区域内容保存在 `data/site-content.json`，重新启动后仍然保留。文字修改不会引入外部跳转链接。

## 城市图片与配文

首页轮播选用用户提供的三张游戏建筑截图：晏阳大会堂、现代商业街区与夕照站前广场。“城市风貌”画廊展示全部五张截图，另两张为住宅楼群与传统院落。影像来源统一标注为“晏阳城市建设服务器”。配文描述截图中的建筑、街道与景观，不将游戏场景写成真实建设新闻。点击图片可查看大图，关闭后继续浏览首页。

在“网站内容”修改轮播和画廊的栏目名称、图片标题与说明。图片保存在网站本地资源目录中，不依赖外部图片服务，构建和双平台部署时一并打包；原始截图文件保持不变。图片来源记录见 `public/assets/image-credits.txt`。

## Windows 部署与局域网访问

使用项目目录 `downloads/3.0.2/` 下的 Windows ZIP，其中包含发布时的文章、草稿和网站区域文字快照；需要当前内容时，在项目目录运行 `npm run package` 导出双平台迁移包。复制 Windows ZIP 到另一台 Windows 10/11 x64 电脑，完整解压后双击“启动网站.cmd”（英文别名 `start.cmd`），浏览器自动打开网站。包内自带经过官方 SHA-256 校验的 Node.js 24.21.0，目标电脑无需安装软件或联网。新电脑首次进入管理模式时重新设置管理员密码。双击“停止网站.cmd”（`stop.cmd`）停止服务，数据会保留。

双击“局域网启动.cmd”（`start-lan.cmd`）可让同一局域网中的电脑访问服务器的 IPv4 地址和端口。首次管理员密码须在服务器本机设置；Windows 防火墙的专用网络权限由使用者自行开启。默认 `start.cmd` 只允许本机访问。端口冲突时，在部署目录的命令提示符中运行 `start.cmd -Port 5174`；PowerShell 使用 `./start.cmd -Port 5174`。切换端口或启动方式前先运行 `stop.cmd`。公网部署需另行配置 HTTPS 与反向代理。

## Linux 部署

使用项目目录 `downloads/3.0.2/` 下的 Linux TAR.GZ；需要当前内容时，在项目目录运行 `npm run package`，与 Windows 包一起导出。适用于 Linux x86_64、glibc 2.28+，例如 Ubuntu 22.04+、Debian 12+；不适用于 Alpine/musl 或 ARM。系统需有 `sh`、`tar`、`sha256sum`、`nohup`，无需安装 Node.js。使用有目录写入权限的普通用户运行：

```sh
mkdir -p yanyang-government
tar -xzf yanyang-government-3.0.2-linux-x64.tar.gz -C yanyang-government
cd yanyang-government
bash start.sh --no-browser
```

默认仅本机访问 `http://127.0.0.1:5173/`，后台 `/admin`。首次启动会校验并解压内置运行环境，服务在后台运行；关闭终端不会停止网站。桌面 Linux 也可运行 `bash start.sh` 尝试自动打开浏览器。停止、改端口和局域网访问：

```sh
bash stop.sh
bash start.sh --port 5174 --no-browser
bash stop.sh
bash start-lan.sh --no-browser
```

首次超级管理员设置仍要求从服务器回环地址访问。远程 Linux 服务器可先在自己的电脑运行 `ssh -N -L 15173:127.0.0.1:5173 用户名@服务器地址`，再在本地浏览器访问 `http://127.0.0.1:15173/admin` 设置账号。切换端口或启动方式前先停止；局域网模式监听所有网卡，网络访问权限按需配置。详细参数及故障排查见 [Linux 部署说明](../deployment/README-linux.txt)。

## 构建与双平台发布

以下命令在源码项目根目录运行：

```sh
npm test
npm run build
npm run verify:build
npm run package
```

`build` 生成可用 `node dist/server.mjs` 运行的完整服务目录，包含后台、文章和网站区域内容快照，不包含管理员账号。`verify:build` 使用隔离数据验证构建版的角色权限、反馈、定时发布和日志。`package` 默认同时生成两种平台的同版部署包，例如：

```text
downloads/3.0.2/yanyang-government-3.0.2-windows-x64.zip
downloads/3.0.2/yanyang-government-3.0.2-linux-x64.tar.gz
downloads/3.0.2/release.json
```

`release.json` 记录两个归档的版本、文件名、字节数和 SHA-256。版本目录保留历史版本；`downloads/yanyang-government-windows-x64.zip` 与 `downloads/yanyang-government-linux-x64.tar.gz` 为当前别名。改动后先更新 `package.json` 版本，再依次执行测试、构建、验证和打包，不发布单个平台。两个包从同一次源码和内容快照生成，任一平台生成失败时命令报错。

首次准备运行环境时从 Node.js 官方站点获取并核验固定 SHA-256，后续可离线打包。为支持在任一平台通过命令行离线导出双平台迁移包，每个包均携带两种运行环境。在源码或部署目录运行 `npm run package`，会将当前文章和网站区域文字导出为同版内容快照；正式版本发布先执行上述测试、构建与验证命令。运行环境校验失败时会拒绝打包。

## 备份与迁移

通过项目目录中的 `npm run package` 导出内容迁移包，再从 `downloads/<版本>/` 获取 Windows ZIP 或 Linux TAR.GZ。迁移包包含全部文章及网站区域文字，新电脑首次运行时重新设置管理员账号。

迁移包包括未发布的草稿，仅分享给接管网站的人员。需要完整备份当前机器的账号、文章和网站区域文字时，先停止服务，再备份整个网站目录，妥善保存 `data`。一键部署启动日志位于 `data/server.log` 和 `data/server-error.log`。具体操作见 [部署操作说明](../deployment/README.txt)。

## 容量与访客功能

容量上限为 10000 篇文章（含草稿），以及 `data/articles.json` 的 UTF-8 文件总大小 64 MiB，先达到任一上限即停止新增或扩大内容。超限操作会被拒绝，已保存的内容会保留。备份导入请求最多 128 MiB，导入后的文章仍须满足上述数量与总容量限制；它不会提高网站的存储上限。接近容量上限时，先通过命令行导出内容迁移包或停止网站后完整备份，再清理不再需要的文章。

支持新闻详情、资讯栏目、站内搜索、城市图轮播、五图城市风貌画廊与大图查看、办事指南、互动答复、意见反馈、长者模式和无障碍模式。留言提交到本网站服务器，由网站管理员查看；本网站不连接真实政务系统。反馈上限为 5000 条或 16 MiB（含处理空间），容量不足时停止接收新留言。
