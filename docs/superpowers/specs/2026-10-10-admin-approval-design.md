# 多管理员与内容审批

用户要求现有管理员升级为超级管理员，超级管理员可以新增账号并拥有全部权限，普通管理员的发布和删除必须经过审批。

旧账号凭据无损迁移到 `admin.json` v2 账号集合，角色为 `superadmin`。普通角色为 `admin`。超级管理员可创建、禁用、删除、重置其他账号密码和调整角色；禁止操作自己的角色、启停与删除，保证至少一个启用的超级管理员。各账号可修改自己的密码。

普通管理员只查看已发布文章、提交发布和删除申请、查看自己的申请。无文章编辑、草稿、网站设置、备份、部署、账号管理与审批权限。后端逐请求检查账号与角色，提交前再次检查，不能通过伪造角色绕过。

发布申请保存验证后的完整文章；删除申请保存目标快照与摘要，批准时目标已修改则返回 409。超级管理员可以批准或驳回并填写理由。批准将文章变化和申请状态放入同一事务日志、同一写队列，防止重复审批与断电后重复执行。申请与账号重启后保存；部署包继续只包含网站内容与文章，不包含账号和审批资料。

保留现有门户与 Windows 一键部署流程，不引入依赖。所有验证使用临时数据，不添加或删除正式文章，不变更原密码。
