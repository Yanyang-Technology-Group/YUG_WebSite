# 管理模式与 Windows 一键部署

用户要求管理员能够发帖，并能一键部署到其他 Windows 10/11 电脑。沿用虚构政府门户与原有无国徽、国旗和外部跳转的约束。

管理模式以同站 `/admin` 入口提供。首次本机设置管理员账号，随后使用密码登录。文章可发布、保存草稿、编辑、删除；字段包括标题、栏目、日期、来源、摘要与正文。首页与搜索只展示已发布内容。内容以 JSON 文件保存在服务器电脑，重启后保留，多浏览器读取同一份文章。

后台提供文章备份导出、经验证的数据恢复与 Windows x64 迁移包。迁移包包含 Node 运行环境、完整页面与后端、当前文章快照、启动/停止脚本与说明，不携带原电脑管理员密码或会话。目标电脑解压后双击启动，首次创建新管理员。默认仅本机访问；另提供显式的局域网启动脚本，显示局域网地址，不自动修改防火墙。

密码采用 scrypt，Cookie 会话采用 HttpOnly、SameSite，修改接口校验同源和 CSRF。静态文件使用允许清单，数据与凭据不可直接下载。文章为纯文本并转义显示。

验证：API 身份认证、CRUD、草稿可见性、持久化、输入校验、恢复、敏感路径防护；部署包实际解压启动，排除凭据；浏览器发布流程和手机排版。
