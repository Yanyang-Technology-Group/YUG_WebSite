# 晏阳联合政府与全站内容管理

用户要求改名为“晏阳联合政府网站”，管理员可以修改任意区域的名称和内容。沿用既有门户布局、文章管理、Windows 免安装部署，保持无国徽、国旗和外部跳转。

新增网站内容配置，用稳定字段键保存纯文本。范围为站点名称与英文副标题、导航和栏目标名、头条/轮播、快捷入口、政策/公开/服务/互动/专题/页脚文字、说明页正文、服务指南和答复。文章正文继续由文章管理编辑。名称与功能路由分离，改名后入口继续有效；列表字段按行或空行分段，不执行 HTML，不把 URL 转为链接。

后台新增“网站内容”，提供区域分类和搜索、输入编辑、保存、未保存提醒及当前区域默认值恢复。数据文件为 data/site-content.json。公开 GET /api/site-content 和认证 GET/PUT /api/admin/site-content 返回或接收 {version:1,values:{key:string}}；字段定义由 site-content-schema.js 共享。缺省新字段补默认，空字符串保留，未知字段、非字符串及超长内容拒绝且不覆盖原配置。

文章备份新增 siteContent，旧文章备份兼容。完整恢复先验证两份内容并用原子事务记录确保同时恢复；部署包包含网站文字快照但不含账号。原有仅示例文章定向更名，管理员原创文章保留。

验证覆盖权限、CSRF、校验失败不改数据、重启保留、旧备份兼容、联合恢复、迁移包快照、名称变化后功能入口及浏览器编辑保存。共享工作区非 Git 仓库，无需 worktree/commit。
