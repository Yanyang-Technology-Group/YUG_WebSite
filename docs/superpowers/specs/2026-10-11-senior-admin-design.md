# 高级管理员与等级管理

角色为普通管理员 `admin`、高级管理员 `senioradmin`、超级管理员 `superadmin`。

高级管理员与超级管理员都可以直接管理文章、草稿、定时发布、全部内容审批、网站内容、反馈、日志、备份与两平台部署包。普通管理员沿用原来的发布和删除审批流程。

超级管理员在管理员管理中可以将其他账号设为任意一种等级。高级管理员可以添加普通或高级管理员，以及管理非超级管理员的密码、启停和删除；不能修改任何现有账号的等级、创建超级管理员或改动超级管理员账号，防止通过重置密码绕过等级管理。每个账号通过账号设置修改自己的密码。不能改变自身等级；至少保留一名启用的超级管理员。

后端在请求入口和提交阶段重新检查权限，成功调整等级撤销目标账号会话。日志支持高级管理员身份，不记录密码和 QQ。兼容旧账号及密码，正式私有数据不用于测试。

正式版本 2.5.0 同时提供 Windows x64 ZIP 与 Linux x64 TAR.GZ，两包版本及内容快照一致。
