# 高级管理员实现计划

> 使用分工实现、独立审查与完成前验证执行；用户已授权完成功能，无需再次设计批准。

**目标：** 新增高级管理员，超级管理员独享其他账号等级调整。

**架构：** 保持现有 Node 服务和浏览器模块，区分全站管理与超级管理员等级权限，不重构持久化格式。

**规格：** [权限设计](../specs/2026-10-11-senior-admin-design.md)

**约束：** 遵循根目录 AGENTS.md，源码修改 public/，验证用临时数据；发布前测试、构建、构建验收，最后生成并核验双平台包。

**审查重点：** 伪造 role 参数；通过超级管理员改密获取等级权限；降级后在途请求提交；高级角色日志重启读取；普通管理员原有审批与反馈能力。
